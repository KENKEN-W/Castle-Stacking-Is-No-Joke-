# 五段重ね将軍

数字を読み、色をそろえ、五段を築け。1〜25の城を5列に積む、1人用の思考型ブラウザパズルです。

## 起動方法

このフォルダの **index.htmlをダブルクリック**してブラウザで開きます。インストール、npm、ビルド、ユーザー登録、APIキーは不要です。index.htmlだけを移動せず、css・jsフォルダと一緒に置いてください。

ファイルを直接開く方法は、今回の検証ツールの制約により実画面では未確認です。ブラウザの設定によっては端末内保存を利用できないことがあります。ゲームは外部通信を必要としない通常のscript読み込みで構成しています。

Node.jsがある環境では、任意の確認方法としてフォルダ内で `node tests/serve.cjs` を実行し、[ローカルのゲーム](http://127.0.0.1:4173/prototype/)を開けます。終了はターミナルでCtrl+Cです。このサーバーは検証用で、ゲームの利用や公開に必須ではありません。

## 遊び方

- 空列にはどの数字でも置けます。城がある列には最上段より大きい数字だけを置けます。各列5城までです。
- 21～25の城は最初の5手には登場せず、6手目以降に登場します。
- 列をクリック・タップ、または数字キー1～5で選びます。TabとEnter／Spaceにも対応しています。
- 14城以下で詰まると、その盤面は0点で戦終了。過去の勝ち戦による累積得点は残ります。
- 15城以上で詰まると、得点を確定する「戦終了」と、その戦の累積得点もすべて捨てる「再合戦」を選べます。
- 15城以上を積み、同色5段が1列以上できると「勝ち戦」。加点して同じ戦を続けます。
- 同色5段で倍率が上がります。戦終了3回の合計得点を競います。
- 3戦終了後、合計得点に応じて「足軽」から「天下統一大将軍」までの評価を表示します。

詳しくはゲーム内の「遊び方」または [RULES.md](RULES.md) を参照してください。

## 自動保存

同じ端末・ブラウザ・サイトで「つづきから」を選ぶと、城の順序や色も含めて再開します。勝ち戦や戦結果の画面から再開しても、得点を二重加算しません。

保存は1枠です。「最初から遊ぶ」で確認すると置き換わります。別端末同期や複数タブの同時プレイには対応していません。ブラウザのデータ削除で進行は失われます。保存できない場合は画面に通知します。

画面テストは一時的にテスト用保存を使い、終了時に元の保存を復元します。テスト中は同じサイトのゲームを操作せず、終了までテスト画面を閉じないでください。

## 後から変更する場所

色とゲームルールは **js/config.js** に集約しています。

- `CASTLE_COLORS`：色名・色コード・識別印・抽選の重み。重み各1で3色が等確率です。
- `MONOCHROME_MULTIPLIERS`：同色完成列0～5列に対応する倍率。
- `MIN_SCORE_CASTLES`：得点と再合戦が可能になる城数。
- `HIGH_CASTLE_MIN`、`HIGH_CASTLE_DELAY_DRAWS`：21以上の城を最初の5手に出さない設定。
- `PLAYER_RANKS`：3戦合計得点から決める評価名と下限点。
- `NUMBER_OF_COLUMNS`、`MAX_STACK_HEIGHT`、`NUMBER_OF_BATTLES`：盤面と戦数。

城の3色以外の画面配色は **css/style.cssの先頭**、案内文は **js/ui.js** にあります。

列数・段数・得点条件を変えた場合は、キーボード範囲、倍率表、案内文、画面幅、テストも合わせて変更してください。保存には設定の識別情報が含まれるため、異なる設定で作った保存は復帰できません。設定変更は既存プレイへの影響も確認して行ってください。

## テストの実行

`tests/index.html` を開くとロジックテストが走ります。「10,000盤面の比較を実行」で配置方針の比較結果も確認できます。

Node.jsがある場合は次のコマンドでも実行できます。追加パッケージは不要です。

```text
node tests/game.test.js
node tests/balance.js
```

画面テストは検証サーバー起動後、[画面テスト](http://127.0.0.1:4173/prototype/tests/ui.html)を開きます。テスト用の盤面を使って再合戦・勝ち戦・結果・保存復帰も確認します。

## GitHub Pagesで公開する手順

今回の作業では公開していません。公開する場合は次の手順です。

1. GitHubで公開用のリポジトリを用意し、このフォルダの内容をアップロードします。index.htmlをリポジトリの最上位に置きます。
2. リポジトリの **Settings → Pages** を開きます。
3. **Build and deployment → Source** を **Deploy from a branch** にします。
4. アップロードしたブランチ（通常はmain）と **/ (root)** を選んで保存します。docsフォルダは公開元に選びません。
5. GitHubに表示された公開URLを開き、開始・保存・スマートフォン操作を確認します。

手順は[GitHub公式クイックスタート](https://docs.github.com/en/pages/quickstart)と[公開サイトの作成手順](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site)に基づきます。全ファイルの参照は相対パスなので、リポジトリ名を含む公開URLにも対応します。
