### 2. 確認したルール

- 3の上に4は配置可能、同値・小さい数字・満杯は不可、空列は配置可能。
- 1～25が各1回。赤・青・緑は独立かつ等しい抽選区間。色で配置判定が変わらない。
- 14城＝0点、15城＝15点、20城＝20点。20城に同色完成列1～4列なら40／60／80／100点。25城・同色5列なら250点。
- 4城だけの同色はボーナス対象外。列ごとの色が異なっても同色完成列として数える。
- 14城で強制戦終了、15城と24城で選択画面へ移る。
- 18城の再合戦で得点は加算されず、同じ戦番号で再開。条件を満たすたび何度でも再合戦可能。
- 勝ち戦25点＋勝ち戦50点＋18点で戦終了すると93点。
- 再合戦では勝ち戦の累積75点を破棄する。終了済みの別の戦の93点は保持する。
- 勝ち戦回数2回・最高25城は、再合戦しても維持する。
- 勝ち戦25点の後で14城の強制戦終了になった場合、戦最終得点は25点。
- 通常・強制の戦終了3回でのみ最終結果へ移る。93＋21＋44＝158点を検算。
- 勝ち戦・戦終了の二重加点、結果の二重操作、26城目の参照を防ぐ。
- 保存復帰で盤面、現在の城、残りの順番と色、得点、参考記録が一致。
- 保存禁止、容量不足、破損JSON、非対応バージョン、数字重複、不正な状態を検出。

仕様書のA10（未来の非表示）、S06（新規開始の確認）、S08（遊び方からの復帰）など画面が必要なケースは、画面テストで補完した。

### 4. 10,000盤面のバランス比較

数字・色の同じデッキを両方針で使用した。両方針とも現在の城と配置済みの列しか参照しない。

- **数字優先：** 置ける列のうち最上段が最大の列へ置く。空列は後回し。
- **同色優先：** 現在の城と同色だけで構成された列を優先し、その中で段数が最大の列へ置く。該当しない場合は数字優先。
- 同順位は左の列を選ぶ。
- 「迷う機会」は、同一の観測盤面で2方針が異なる配置先を選ぶ場面、と定義した。同色5段の完成可能性を保証する指標ではない。
- 各盤面は配置不能または25城で終了し、再合戦や勝ち戦後の継続は含めない。

| 指標 | 数字優先 | 同色優先 |
| --- | --- | --- |
| 15城以上到達 | 4,939盤面（49.39%） | 3,438盤面（34.38%） |
| 同色5段を1列以上完成（15城未満も含む） | 106盤面（1.06%） | 252盤面（2.52%） |
| 勝ち戦 | 16盤面（0.16%） | 6盤面（0.06%） |
| 平均積載数 | 14.5046城 | 13.2728城 |
| 平均盤面得点 | 8.8581点 | 6.1673点 |
| 配置方針が分かれる機会を含む盤面 | 7,044盤面（70.44%） | 7,044盤面（70.44%） |
| 方針が分かれた配置判断数 | 14,328／145,046 | 11,827／132,728 |

**同色を優先すると、同色完成率は上がり、15城到達率は下がった。** 色を狙った代償として0点になるリスクが確認できる。一方、同色5段の完成自体はこの単純な方針では少ない。70.44%という機会の値を、完成率や「毎ゲーム役が取れる」保証と解釈しない。

これは2つの固定方針の比較であり、人間の最適な判断や3戦＋再合戦を含めた実際のゲーム体験を表すものではない。人による試遊で役の狙いやすさを評価する余地がある。ユーザーが確定した3色・独立抽選・15城条件は変更していない。
